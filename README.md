# 🦷 Landing Page - Dr. Hélio Russo Odontologia

Uma landing page moderna, responsiva e interativa desenvolvida para a clínica odontológica Dr. Hélio Russo. O projeto apresenta a estrutura da clínica, equipe de profissionais, tratamentos oferecidos, depoimentos e uma seção interativa de FAQ (Perguntas Frequentes).

---

## 📌 Funcionalidades

- **Menu Mobile / Hambúrguer:** Animação customizada em CSS e JavaScript para navegação intuitiva em dispositivos móveis.
- **Seção FAQ & Tratamentos Interativa:** Acordeões em JavaScript com transições suaves para expansão e exibição de detalhes.
- **Galeria e Vídeo:** Integração com vídeo do YouTube para apresentação do espaço físico.
- **Grid de Equipe:** Exibição dinâmica da equipe médica com suporte a layout responsivo (CSS Grid).
- **Design Responsivo:** Adaptado para diferentes tamanhos de tela (Mobile First / Media Queries para desktop).
- **Botão Flutuante:** Atalho fixo na tela para contato rápido via WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout flexbox/grid, animações e variáveis CSS.
- **JavaScript (Vanilla):** Manipulação da DOM para eventos de clique, animação do menu e sanfonamento do FAQ/Tratamentos.
